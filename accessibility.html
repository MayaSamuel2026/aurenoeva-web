Our target

We use WCAG 2.2 AA as the practical design target for the public website, including keyboard access, visible focus, semantic structure, text alternatives for informative images, readable contrast and responsive layouts.

Current measures

  • Semantic headings and landmark structure.
  • Keyboard-reachable navigation and controls.
  • Skip-to-content link.
  • Responsive design for desktop and mobile.
  • Text labels rather than icon-only critical actions.
  • Local vector illustrations with alt text.
  • Forms with explicit labels and focus states.

Feedback

If you encounter an accessibility barrier, email info@aurenoeva.com with the page, device / browser and the problem you encountered. We will use the report to prioritise a correction.

Status

This statement describes the current public website design. A final production accessibility check should be run after hosting, backend integrations, third-party scripts and final content have been added.

Unser Ziel

Für die öffentliche Website orientieren wir uns praktisch an WCAG 2.2 AA, einschließlich Tastaturbedienung, sichtbarem Fokus, semantischer Struktur, Textalternativen, ausreichendem Kontrast und responsiven Layouts.

Aktuell umgesetzt

  • Semantische Überschriften und Seitenbereiche.
  • Per Tastatur erreichbare Navigation und Bedienelemente.
  • Sprunglink zum Hauptinhalt.
  • Responsive Gestaltung für Desktop und Mobilgeräte.
  • Textbeschriftungen für kritische Aktionen.
  • Lokale Vektorillustrationen mit Alternativtext.
  • Formulare mit eindeutigen Labels und Fokuszuständen.

Feedback

Wenn Sie auf eine Barriere stoßen, schreiben Sie an info@aurenoeva.com und nennen Sie Seite, Gerät / Browser und das Problem. Wir nutzen die Meldung zur Priorisierung einer Korrektur.

Status

Diese Erklärung beschreibt den aktuellen Stand der öffentlichen Website. Nach der finalen Einbindung von Hosting, Backend und möglichen Drittanbieterdiensten sollte die Barrierefreiheit in der Produktionsumgebung nochmals vollständig geprüft werden.
